# 任天堂实战设计模板与体检诊断量表 (Templates & Diagnostic Rubrics)

本文件提供可以直接用于游戏立项、关卡策划、机制评审与体验打磨的工程化模板及诊断打分表。

---

## 模板 1：任天堂式单页玩具提案卡 (One-Page Toy Concept Sheet)

适用于游戏立项初期，验证核心机制是否具备“纯粹玩具趣味”与“复合解题潜能”。

```markdown
# 【项目/核心机制名称】单页玩具提案卡

## 1. 核心玩具动词 (The Core Toy Verb)
- **唯一核心动词**：（例如：伸缩舌头 / 投掷帽子 / 喷射墨汁 / 磁力抓取）
- **物理操作手感描述**：（按键的直观触觉、按压蓄力与释放的动量反馈）
- **空白白盒测试标准**：（在没有敌人和剧情的纯白房间里，玩家仅凭把玩这个动作能玩出什么自发乐趣？）

## 2. 宫本茂“复合解题”验证矩阵 (Multi-Solution Matrix)
本机制必须同时优雅解决以下至少 3 个维度的设计挑战：
- **挑战 1 (核心通关/位移)**：如何通过该动作移动/越过地形？
- **挑战 2 (战斗/互动交互)**：如何通过该动作击退敌人或改变世界状态？
- **挑战 3 (资源/引导/容错)**：该动作如何附带解决收集、资源循环或降低死亡挫败感？

## 3. 枯竭技术的水平思考 (Lateral Thinking Evaluation)
- **依赖的基础成熟技术**：（如基础 2D 碰撞体、射线检测、简单物理关节等）
- **放弃的华而不实复杂度**：（明确砍掉哪些对玩法核心无贡献的复杂模拟）
- **全年龄直觉共鸣点**：（与现实生活中哪种经验直接对应？如像粘蝇板一样粘住东西/像弹弓一样弹射）

## 4. 机制扩张蓝图 (Multiplication Expansion)
当该核心动作与以下基础系统发生碰撞时，会自然产生什么有趣的连锁反应？
- 与【火/水/电/风】的交互：
- 与【重力/物理运动】的交互：
- 与【敌人行为】的交互：
```

## 模板 2：“起承转合”4步关卡策划表 (Kishōtenketsu Level Design Sheet)

适用于设计单一关卡或一个完整的关卡章节。

```markdown
# 【关卡编号/名称】：____________________
- **本关核心机制/机关 (Gimmick)**：____________________
- **通关预计时长**：2 ~ 4 分钟
- **基调色彩与音乐节拍**：____________________

---

### 第 1 步：起 (Introduction) —— 安全引入
- **安全沙盒环境**：[描述封闭地形，无即死悬崖与强敌]
- **机制显性特征**：[机关的外观、高光或诱导性符号]
- **玩家的顿悟瞬间**：[玩家在此处如何无意或本能学会新机制]

### 第 2 步：承 (Development) —— 标准检验
- **标准挑战场景**：[在正常地形/悬崖上加入该机制的运用]
- **轻度威胁元素**：[加入 1 种初级敌人或有规律的计时障碍]
- **失败代价**：[掉回底层或扣除 1 格生命，可立即重新尝试]

### 第 3 步：转 (Twist) —— 意外变体与复合冲击
- **颠覆性变量**：[改变节拍、重力反转、机制联动或追击战]
- **思维转换点**：[玩家原有的操作习惯在这里需要发生何种变化？]
- **张力峰值设计**：[视觉与音效如何配合制造紧张感？]

### 第 4 步：合 (Conclusion) —— 高潮释压与成就结算
- **大师级综合大考验**：[连续 2~3 次完美施展该机制的舞台]
- **终点与奖励结算**：[金色旗杆/大宝箱/通关礼花与赞美音效]
- **通关后的情绪状态**：[畅快淋漓、成就感爆棚]

---

### ★ 进阶分流：樱井政博“风险与回报”支线 (Risk & Reward)
- **安全大道 (Casual Path)**：[平稳通关，保底通关奖励]
- **高危支线 (Hardcore Path)**：[悬崖外侧/高空窄道]
- **贪婪诱饵 (Greed Reward)**：[大金币/稀有收集物/终极捷径]
```

## 模板 3：探索与三角法则空间布局卡 (Triangle & Exploration Beat Card)

适用于 3D 开放世界区域、大地图或立体箱庭场景规划。

```markdown
# 【区域/箱庭空间名称】：____________________

## 1. 宏观极点与地标引力 (Landmark Gravitational Pull)
- **1 级宏观大尺度地标 (远处天际线)**：[无论身处何地抬头可见，如高塔、巨树、火山]
- **2 级中尺度阶段目标 (3 分钟路程)**：[视野中发光的神庙、高耸驿站、奇怪的遗迹]

## 2. 三角法则地形切割 (Triangle Occlusion & Reveals)
- **主三角山丘/建筑位置**：
- **遮蔽视线后的惊喜 (Occluded Surprise)**：[当玩家转过山脊或攀上峰顶时，眼前骤然展现的全新景观]
- **玩家路线二选一权衡**：
  - 路径 A (攀爬登顶)：[体力消耗高，获得开阔滑翔视野]
  - 路径 B (峡谷绕行)：[体力消耗低，遭遇隐蔽敌人营地或采集点]

## 3. 10~30 秒微尺度好奇心链条 (Curiosity Breadcrumbs)
沿途设置的微型吸引子链条：
1. **[00:15 秒]**：[奇怪排列的小石块 / 树洞闪光] $\rightarrow$ 获得微奖励
2. **[00:45 秒]**：[远处袅袅升起的青烟 / 飞行的怪鸟] $\rightarrow$ 触发小奇遇
3. **[01:15 秒]**：[破损风车 / 倒塌石柱] $\rightarrow$ 发现隐藏地下洞口
```

## 模板 4：任天堂设计健康度体检表 (Nintendo Design Diagnostic Rubric)

当评估现有游戏方案或原型时，使用以下 6 大维度（每项 0~5 分，总分 30 分）进行外科手术式体检。

| 评估维度 | 核心检验标准 | 得分 (0~5) | 典型扣分项 (Red Flags) | 优化建议 (Action Items) |
| :--- | :--- | :--- | :--- | :--- |
| **1. 玩具感先行 (Toy-First)** | 核心控制是否具有物理愉悦感？白盒原型是否已经非常好玩？ | | 光移动跳跃很枯燥，全靠美术和华丽特效撑场面。 | 调优基础加速度、惯性刹车、下落重力与起跳曲线。 |
| **2. 复合解题度 (Multi-Solution)** | 核心机制是否一招多用，同时化解位移、战斗与资源循环痛点？ | | 遇到一个新需求就增加一个新按键/独立系统，系统极其臃肿。 | 尝试合并 2~3 个功能到单一物理动作中，砍掉冗余系统。 |
| **3. 去文字化与隐性教学 (Invisible Guidance)** | 是否完全杜绝长篇说明书弹窗？玩家能否通过场景几何与安全试错领悟规则？ | | 开局弹出一页又一页新手指引，玩家边看边忘。 | 建立 World 1-1 式安全沙盒，用金币抛物线和敌人走位引导。 |
| **4. 手感与隐性容错 (Game Feel & Grace)** | 是否配置了土狼时间 (4~6帧)、输入缓冲 (5~8帧)、卡肉顿挫与定向震屏？ | | 边缘起跳经常踩空摔死；攻击轻飘飘像打空气；按键偶尔吞输入。 | 注入标准 Game Feel 容差物理参数与 3~6 帧命中卡肉。 |
| **5. 关卡起承转合 (Kishōtenketsu)** | 关卡是否有明确的“起-承-转-合”4步递进？是否存在呼吸释压区？ | | 关卡平铺直叙毫无波澜，或者一上来就高难劝退。 | 重构为“安全学习 $\rightarrow$ 运用 $\rightarrow$ 意外变体 $\rightarrow$ 高潮终点”四段流。 |
| **6. 风险与回报 (Risk & Reward)** | 玩家能否自主选择挑战难度？高风险操作是否有与之匹配的即时高额回报？ | | 只有单一路线，手残打不过，高玩觉得无聊；或者冒险去拿宝箱只给无用垃圾。 | 在主干道旁设计“贪婪诱饵”分支，将高价值奖励挂在悬崖边缘。 |

### 综合健康度评级：
- **26 ~ 30 分 (S 级)**：纯正任天堂水准，极佳的直觉化乐趣与高黏性。
- **20 ~ 25 分 (A 级)**：优秀作品，少数手感或教学细节可进一步去文字化与精细打磨。
- **14 ~ 19 分 (B 级)**：机制略显臃肿或教学过于生硬，需进行“复合解题合并”与“隐性容错注入”。
- **< 14 分 (需重构)**：缺乏纯粹玩具感，过度依赖文字灌输与繁杂系统，建议回退至白盒阶段重做核心动词。
