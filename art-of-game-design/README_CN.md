## 📖 简介

Jesse Schell 的《游戏设计的艺术：透镜之书》（*The Art of Game Design: A Book of Lenses*）被公认为游戏设计界的终极方法论宝典。全书将游戏剖析为**机制、故事、美学、技术**四大基本元素，并提炼出 113+ 面多维视角的思考“透镜（Lenses）”。

本 Skill 将书中的全套理论、四元组共生架构、12 维平衡调校模型与实战评估量表深度结构化，让 AI Agent 成为你的资深系统策划与游戏哲学顾问，支持：

1. **四元组与统一主题共创 (Tetrad & Theme)**：从核心体验出发，确保机制、故事、美学与技术的全息协同，杜绝各模块割裂。
2. **113+ 全景透镜靶向诊断 (Lenses Diagnostics)**：通过佩戴特定透镜，精准穿透设计瓶颈（如玩家无能动性、最优解支配、沉浸感断裂、奖励疲劳）。
3. **12 维系统平衡与心流调优 (Balance & Flow)**：精调技能 vs 运气、脑力 vs 体力、虚拟经济水源/水槽（Sources/Sinks）循环与动态心流通道。
4. **间接控制与心理学引导 (Indirect Control)**：运用视觉诱饵、灯光引导、碰撞启发与内在动机驱动玩家行为。

## ⚡ 安装方式

通过你的 AI Agent 直接安装本 Skill：

### 方式 1：AI 提示词安装（推荐）

在与 AI 对话时发送以下指令：

```text
请帮我从 https://github.com/Wilson520403/art-of-game-design-skill.git 克隆并安装 Art of Game Design skill 到我的全局 skills 目录。
```

### 方式 2：命令行克隆

```bash
git clone https://github.com/Wilson520403/art-of-game-design-skill.git ~/.config/skills/art-of-game-design
```

## 🎯 使用示例

安装完成后，在与 AI 交流时直接自然语言触发：

- **四元组与主题构思**: *“我想做一款赛博朋克背景的黑客解谜游戏，请用《透镜之书》的【元素四元组】帮我规划机制、故事、美学与技术的全息统一方案。”*
- **透镜靶向问诊**: *“玩家反馈我们的动作游戏打斗很爽但玩久了很空虚，请调出【#2 惊喜透镜】【#21 心流透镜】【#39 动机透镜】为机制做一次深度诊断。”*
- **12 维平衡与经济调优**: *“我们设计了一套装备强化系统，但后期金币泛滥且付费与非付费玩家差距过大，请从【经济系统水源/水槽】与【技能与偶然透镜】角度给出调优方案。”*
