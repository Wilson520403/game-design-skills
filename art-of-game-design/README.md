## 📖 Overview

*The Art of Game Design: A Book of Lenses* by Jesse Schell is universally recognized as the quintessential bible of game design methodology. It deconstructs games into four fundamental pillars (**Mechanics, Story, Aesthetics, Technology**) and provides **113+ analytical lenses** for multi-perspective inquiry.

This Skill turns Schell's philosophy into an actionable AI mentor capability that supports:

1. **Elemental Tetrad & Unifying Theme Co-Design**: Align mechanics, narrative, art, and technology holistically around a singular core experience.
2. **113+ Lenses Targeted Diagnostics**: Diagnose gameplay bottlenecks, player agency issues, dominant strategy exploits, and reward fatigue through specialized lenses.
3. **12 Dimensions of Game Balance & Flow Tuning**: Balance skill vs. chance, mental vs. physical effort, economy sources & sinks, and dynamic difficulty flow channels.
4. **Indirect Control & Player Psychology**: Guide player behavior seamlessly via visual cues, lighting heuristics, diegetic interfaces, and intrinsic motivators.

## ⚡ Installation

Install this skill directly via your AI Agent:

### Option 1: AI Prompt Installation (Recommended)

Paste this instruction into your AI Agent chat:

```text
Please install the Art of Game Design skill into my global skills directory from https://github.com/Wilson520403/art-of-game-design-skill.git
```

### Option 2: Command-Line Installation

```bash
git clone https://github.com/Wilson520403/art-of-game-design-skill.git ~/.config/skills/art-of-game-design
```

## 🎯 How to Use

Once installed, prompt your AI naturally in any game design conversation:

- **Tetrad Co-Creation**: *"I want to create a cyberpunk stealth puzzle game. Walk me through the Elemental Tetrad to ensure mechanics, story, aesthetics, and technology are in sync."*
- **Lenses Deep Audit**: *"Playtesters say combat feels repetitive after 2 hours. Audit our mechanics using Lens #2 (Surprise), Lens #21 (Flow), and Lens #39 (Meaningful Choice)."*
- **Economy & Balance**: *"Our crafting economy is inflating too fast and players are hoarding gold. Balance our sources and sinks based on Schell's game balance framework."*
