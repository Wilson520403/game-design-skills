# 实战设计模板与体检量表 (Templates & Diagnostic Rubrics)

> “一份清晰的体检表能让你在原型阶段发现 80% 的隐蔽系统缺陷，避免在量产阶段付出百倍代价。”  
> —— Jesse Schell，《游戏设计的艺术》

---

## 模板 1：元素四元组与统一主题提案卡 (Tetrad Pitch Sheet)

```markdown
# 【游戏项目名】元素四元组概念提案卡

### 一、 核心概念与统一主题 (Core Theme & Experience)
- **High Concept（一句话卖点）**：[一句话概括：玩家扮演什么角色，在何种独特世界中，体验怎样的核心乐趣]
- **统一主题 (Unifying Theme)**：[定义全作的核心思想灵魂，如“羁绊战胜虚无”、“贪婪的代价”]
- **本质体验目标 (Essential Experience)**：[希望唤醒玩家的 2~3 个核心生理/情绪感受，如：命悬一线的压迫感、解开谜题的顿悟感]
- **魔法单词 (The Secret Word)**：[用 1 个词定义游戏灵魂，如：Balance / Solitude / Rhythm]

---

### 二、 元素四元组协同映射 (Elemental Tetrad Mapping)

#### 1. 机制 (Mechanics - 规则与交互)
- **核心操作动词 (Core Verbs)**：[玩家最频繁按下的 2~3 个动作，如：跳跃、附身、投掷]
- **核心系统循环 (Core Loop)**：[动作 -> 反馈 -> 资源积累 -> 能力升级 -> 迎接新挑战]
- **空间与时间规则**：[连续/离散、回合/即时、空间拓扑约束]

#### 2. 故事 (Story - 叙事与世界)
- **世界观前提 (Premise)**：[故事背景、核心冲突起源]
- **主角欲望与阻碍**：[角色想要什么？是什么在拼命阻止他？]
- **玩家投射形式**：[空白替身 vs 预设鲜明主角]

#### 3. 美学 (Aesthetics - 声画与触感)
- **视觉风格与色调**：[视觉调性、核心色彩规范]
- **音频质感**：[背景音乐风格、音效物理质感]
- **Juice 微反馈**：[命中顿挫、屏幕震颤、界面排版触感]

#### 4. 技术 (Technology - 平台与支撑)
- **目标平台与输入媒介**：[PC/主机手柄/触屏/VR]
- **核心技术挑战**：[物理模拟、网络同步、同屏粒子、无缝加载]

---

### 三、 全息设计一致性自查 (Holographic Alignment)
- [ ] 机制是否在直接讲述故事？
- [ ] 美学风格是否提供了直观的机制示能？
- [ ] 技术选型是否完美支撑了机制的极致手感？
```

## 模板 3：12 维游戏平衡体检量表 (12-Dimension Balance Rubric)

对系统进行多维度打分（1~5 分），并记录诊断记录与调优策略：

```markdown
| 序号 | 平衡维度 (Dimension) | 状态评估 (1~5分) | 潜在失衡风险排查 | 调优行动方案 |
| :---: | :--- | :---: | :--- | :--- |
| **1** | **技巧 vs 偶然** |  | 是否过度依赖运气导致挫败？纯技巧是否导致新手被劝退？ |  |
| **2** | **脑力 vs 体力** |  | 策略规划与极限反应是否产生割裂？ |  |
| **3** | **竞争 vs 合作** |  | 赢家是否过早滚雪球？合作是否存在搭便车划水现象？ |  |
| **4** | **简短 vs 漫长** |  | 单局时长是否匹配受众？失败后重试跑图是否冗长？ |  |
| **5** | **奖励 vs 惩罚** |  | 惩罚是否具有教学意义？奖励是否刺激了内在动机？ |  |
| **6** | **自由 vs 控制** |  | 玩家是否迷茫无目标？线性引导是否过于死板逼仄？ |  |
| **7** | **简单 vs 复杂** |  | 是否做到了“易于上手，难于精通”？有无冗杂说明书？ |  |
| **8** | **短/长期目标** |  | 玩家当前一秒与未来一小时的目标是否均清晰明确？ |  |
| **9** | **有意义的选择** |  | 是否存在统治级最优解 (Dominant Strategy) 扼杀多样性？ |  |
| **10**| **动态难度 DDA** |  | 难度阶梯是否平滑？心流通道是否避免了焦虑与厌倦？ |  |
| **11**| **经济水龙头/沉没口**| | 产出与消耗是否动态平衡？有无恶性通胀或经济死锁？ |  |
| **12**| **细节 vs 想象** |  | 是否精准展示了 10% 核心魅力，为玩家留出脑补空间？ |  |
```

## 模板 4：经典谜题设计 10 问排查表 (Puzzle 10-Question Checklist)

依据 Jesse Schell 谜题设计法，在关卡中加入解谜环节前逐项检查：

- [ ] **Q1. 目标是否一目了然？**（玩家看到谜题第一眼就知道“成功解开”是什么状态，而非瞎猜通关条件）。
- [ ] **Q2. 规则是否容易上手？**（操作方式直观，不需要查阅繁复的操作手册）。
- [ ] **Q3. 是否具备渐进感 (Sense of Progress)？**（每解开一步，谜题会给予阶段性视觉/听觉反馈）。
- [ ] **Q4. 难度阶梯是否合理？**（前置谜题是否教导了后续大谜题所需的思维原子）。
- [ ] **Q5. 是否存在顿悟时刻 (Aha! Moment)？**（答案来自于逻辑洞察，而非机械式的穷举试错）。
- [ ] **Q6. 提示系统是否隐性克制？**（卡关时给予渐进式线索，不直接粗暴报答案）。
- [ ] **Q7. 是否能调动玩家的直觉常识？**（物理规律、重力、导电、浮力等符合心智模型）。
- [ ] **Q8. 失败成本是否低廉？**（解错后能一键重置或瞬间撤回，不强制长时间惩罚）。
- [ ] **Q9. 谜题是否融入了世界观故事？**（是古代神庙的合理机关，还是突兀出现的数独棋盘？）。
- [ ] **Q10. 解开后是否有丰厚的情感/实质回报？**（成就感、密室大门缓缓开启的震撼视听）。

## 模板 5：终极问题与发布准备清单 (Ultimate Question & Polish Checklist)

- [ ] **【#6 终极问题透镜】**：我们到底在解决什么核心体验问题？这个游戏真的配得上玩家宝贵的时间吗？
- [ ] **【#113 魔法单词透镜】**：游戏是否贯彻了那个神圣的“核心灵魂词汇”？
- [ ] **【#37 隐性容错透镜】**：操作判定、边缘跳跃、输入缓冲是否足够宽容丝滑？
- [ ] **【#47 触觉反馈透镜】**：每一个按键交互的视听微震反馈是否饱满多汁 (Juicy)？
- [ ] **【#100 魔法单词透镜】**：所有参与制作的伙伴是否为之由衷骄傲？
