# 游戏设计实战模板与检查清单 (Templates & Checklists)

本文件汇集了《游戏设计梦工厂》（Game Design Workshop）实操流程中最核心的 5 大模板与评估清单。

---

## 模板 2：以玩为中心的核心 GDD 大纲 (Playcentric GDD Outline)

```markdown
# [游戏名称] 核心设计文档 (Game Design Document)

## 1. 概述与体验愿景 (Executive Summary & Vision)
- 游戏类型 (Genre):
- 核心体验目标 (Player Experience Goals):
- 故事与戏剧前提 (Dramatic Premise):

## 2. 形式元素规范 (Formal Elements Specification)
- **玩家结构 (Players)**: 玩家数量、交互模式（合作/对抗/非对称）、角色定义。
- **目标系统 (Objectives)**: 主目标（胜利/通关条件）、次要目标（阶段任务/收集品）。
- **规程与流程 (Procedures)**: 开局设置、每回合/实时输入流程、特殊事件触发、终局结算。
- **核心规则集 (Rules)**: 动作限制、伤害判定公式、死亡/失败惩罚。
- **资源系统 (Resources)**: 资源类型表（生命、金币、精力、空间、信息）、产出与消耗链条（Sinks & Sources）。
- **冲突与阻碍 (Conflict)**: 敌人 AI 行为树、关卡陷阱阻碍、资源权衡困境。
- **边界与魔圈 (Boundaries)**: 地图空间边界、时间限制、规则适用范围。
- **终局与结算 (Outcomes)**: 计分体系、胜利/失败展示、重玩奖励。

## 3. 戏剧与叙事系统 (Dramatic Elements)
- **角色设计 (Characters)**: 主角背景与动机、NPC 互动规则、反派驱动力。
- **叙事弧线 (Dramatic Arc)**: 章节结构、关键剧情转折点（Beat Sheet）、与关卡难度的对应关系。
- **世界观与视听风格 (World & Aesthetics)**: 世界法则、视觉基调、环境叙事要点。

## 4. 核心系统动力学 (System Dynamics)
- **正反馈设计 (Positive Feedback)**: 滚雪球机制与终结手段。
- **负反馈设计 (Negative Feedback)**: 动态平衡与翻盘机会保护。

## 5. 关卡与进程 (Progression & Level Design)
- 技能解锁与心流曲线 (Flow Curve)。
- 阶段性难度与机制教学（引导 -> 练习 -> 考验 -> 变奏）。
```

## 模板 3：实体/极简原型验证清单 (Prototyping Checklist)

在制作原型和开始测试前，逐项检查：

- [ ] **核心假设明确性**: 是否写下了本轮原型要测试的具体假设（而非“看看好不好玩”）？
- [ ] **机制最小化**: 是否剥离了所有非核心机制（例如：先不要做背包系统，只验证战斗技能搭配）？
- [ ] **材料与可修改性**: 规则和数值是否能用纸笔在 10 秒内涂改调整？
- [ ] **极端情况预演 (Stress Test)**:
  - [ ] 如果玩家一直采取最保守/挂机策略会怎样？
  - [ ] 如果玩家全部资源投入单一点（偏科打法）是否会破坏游戏？
  - [ ] 是否存在任何死循环或无法结束的死锁状态？
- [ ] **单局时长控制**: 原型单局是否能在 5-15 分钟内完成快速验证？

## 5. 模板 5：游戏机制健康度体检表 (Mechanics Diagnostic Rubric)

用于对已有策划案或机制进行结构化诊断打分（1-5 分制）：

| 评估维度 | 核心检验问题 | 评分 (1-5) | 诊断要点与改进建议 |
| :--- | :--- | :--- | :--- |
| **1. 玩家能动性 (Agency)** | 玩家的选择是否具有实质性影响，还是伪选择？ | | |
| **2. 目标清晰度 (Objective Clarity)** | 玩家在任何时刻是否都知道自己“下一步该干什么”？ | | |
| **3. 决策有意义度 (Meaningful Choice)** | 是否存在两难困境与风险收益权衡？是否存在唯一无脑最优解？ | | |
| **4. 规则完备性 (Rule Completeness)** | 边界条件、胜负判定与资源消耗是否逻辑闭环？ | | |
| **5. 反馈及时性 (Feedback Loop)** | 系统的正负反馈是否健康？落后玩家是否有悬念，领先玩家是否有爽感？ | | |
| **6. 戏剧与玩法契合度 (Ludonarrative)** | 机制的操作手感与规则是否契合故事情境与情感目标？ | | |
| **7. 学习曲线与心流 (Flow Curve)** | 挑战攀升是否平滑？是否存在突兀的难度悬崖或过长的无聊期？ | | |
